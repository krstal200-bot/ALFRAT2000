# مستودع قطع الغيار

تطبيق ويب (PWA) لتتبع مخزون قطع غيار الهواتف: Apple, Samsung, Xiaomi, Huawei, Oppo.
بدون حساب أو إيميل. البيانات تتزامن بين كل أجهزتك عبر Firestore المجاني.
رمز القفل يُضبط من **الإعدادات ⚙️ داخل التطبيق**، ويُطلب عند الإضافة والحذف وتعديل الكمية فقط.

## الإعداد (مرة واحدة)
1. أنشئ مشروعاً في [Firebase Console](https://console.firebase.google.com) وأضف **Web app**، وانسخ الإعدادات إلى `firebase-config.js`.
2. **Firestore Database**: أنشئ قاعدة بيانات، ثم من تبويب Rules الصق محتوى `firestore.rules`.
3. ارفع الملفات إلى مستودع GitHub، ثم **Settings ← Pages ← Deploy from branch ← main / root**.
4. افتح الرابط، ثم ⚙️ ← فعّل رمز القفل. ومن الموبايل اختر "إضافة إلى الشاشة الرئيسية".
5. للحصول على APK استخدم [PWABuilder](https://www.pwabuilder.com) بإدخال رابط الصفحة.

## ملاحظة أمان
الرمز حماية على مستوى التطبيق (يُخزَّن مشفّراً SHA-256 في قاعدة البيانات). لا تشارك رابط التطبيق مع من لا تثق به،
فمن يملك إعدادات Firebase ومعرفة تقنية يستطيع تجاوز القفل. القواعد تمنع على الأقل إضافة حقول غريبة.
